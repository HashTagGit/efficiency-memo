--------------------------------------------------------------------------------
Root Cause Pattern
--------------------------------------------------------------------------------
The file is a vitest spec (uses describe/it/expect from vitest), but the
shared package's tsconfig is configured for tsc-only type emission. As
a result, the vitest globals and the test-local ExpectString/ExpectNumber
type-level helpers (used to express "the type is exactly this primitive")
are not visible to tsc.

Concretely:
  - "Cannot find name 'expect'"          -> vitest global not in tsc scope
  - "Expression is not callable"        -> ExpectString/ExpectNumber are
    declared as types (or value-space proxies) but invoked as functions
  - "Types of property 'enabled' ..."  -> ExpectExtends<...> helper used
    in satisfies-position without proper const-narrowing at the call site

This is a tooling/test-type-definition problem, NOT a production code
bug. The same file PASSES at runtime (16/16 vitest tests green) - see
task-0-baseline.txt.
