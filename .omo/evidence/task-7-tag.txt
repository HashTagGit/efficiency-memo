NOTE on acceptance-criteria wording:
  For an ANNOTATED tag, `git rev-parse <tag>` returns the SHA of
  the tag OBJECT (which contains the tagger/message and dereferences
  to a commit), not the SHA of the underlying commit. This is correct
  git behavior; lightweight tags would directly return the commit SHA.

  To verify the commit the tag points to, the canonical git command
  is `git rev-parse <tag>^0` (or `git log -1 --format=%H <tag>`).
  Both return the commit SHA, which must equal HEAD.

$ git rev-parse --verify v0.0.1^0
