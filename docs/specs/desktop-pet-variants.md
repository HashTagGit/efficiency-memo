# Desktop pet variant packages (V3)

A V3 package groups several Codex Pet sheets under one pet identity. Use it when one
character has multiple whole-body forms that should not appear as separate pets in Pet
Assistant.

## Manifest

`apps/desktop/src/assets/pets/<id>/pet.json` keeps the single-package fields and adds
`defaultVariant` plus `variants`:

```json
{
  "id": "mole-baby",
  "displayName": "Mole Baby",
  "description": "The round Lamu mole across its seed, growth, and evolution forms.",
  "spriteVersionNumber": 3,
  "defaultVariant": "middle",
  "variants": [
    {
      "id": "seed",
      "displayName": "种子期",
      "description": "花盆中轻轻摆动的拉姆种子。",
      "spriteVersionNumber": 1,
      "spritesheetPath": "variants/seed.png",
      "sleepingFrame": { "row": 0, "column": 3 }
    },
    {
      "id": "middle",
      "displayName": "中级拉姆",
      "description": "长出两片嫩叶的中级拉姆。",
      "spriteVersionNumber": 1,
      "spritesheetPath": "variants/middle.png"
    }
  ]
}
```

- `spriteVersionNumber: 3` identifies a collection; a variant declares its own `1` or `2`
  sheet version, so a future V2 variant can add gaze rows without changing the package.
- Variant ids are `[A-Za-z0-9_-]{1,64}`; they must be unique and `defaultVariant` must name
  one of them. A collection has 2–64 variants.
- `spritesheetPath` is relative to the package folder and may point into a subdirectory
  (`variants/`). Absolute paths, `..`, backslashes, and control characters are rejected.
- `sleepingFrame` is optional and must be inside the variant's atlas grid. It lets a form
  without a closed-eye idle frame declare the frame used by the sleeping pose.
- Single-sheet packages keep `spriteVersionNumber: 1 | 2`; they are discovered exactly as
  before and never need a `variants` block.

## Catalog and selection

- `discoverBundledDesktopPetCatalog` splits manifests into `BUNDLED_PETS` (V1/V2) and
  `BUNDLED_COLLECTIONS` (V3). A collection is one entry with `variants`, `defaultVariant`,
  and a resolved atlas per variant.
- `loadDesktopPetSprite(petId, variantId)` resolves variant atlases; an unknown or missing
  variant falls back to `defaultVariant`.
- Pet Assistant renders single pets as before and each collection as one labelled group
  with a form radio per variant. Selecting a form saves both `selected_pet_id` and
  `selected_pet_variant`.
- The desktop pet window receives `petVariant` through `select_desktop_pet`, loads the
  matching atlas, and uses the variant's `sleepingFrame` for the sleeping pose.
- Migration 0024 adds the nullable `selected_pet_variant` column. Existing rows keep
  working: a null variant resolves to the collection's `defaultVariant` at startup. Legacy
  backups (schema ≤ 23) are upgraded by the normal migration path.

## Import and packaging

- Imported V3 packages must arrive as a **ZIP** containing `pet.json` and every variant
  sheet. The importer validates each variant's dimensions, transparency cells, and
  thumbnail before storing rows.
- Each imported variant is stored in `desktop_pet_packs` under `<collectionId>:<variantId>`
  with a `collection` metadata block; the catalog groups those rows back into one entry.
  Single-sheet imports are unchanged.
- Bundled packages are generated by scripts. For mole-baby, run:

  ```bash
  python scripts/build-mole-baby-collection.py \
    --assets path/to/mole-baby/public/assets \
    --output apps/desktop/src/assets/pets/mole-baby
  ```

  The script copies the eight adult atlases after clearing unused cells and composes the
  96×99 seed cells (plus its separate pot layer) onto the 192×208 V1 grid. Seed cells
  sample the upstream 61-frame loop across the nine tracks, and the closed-eye frame is
  marked as `sleepingFrame`. The `classic` atlas inherits clipped top leaves from the
  upstream export; re-export it before using it as a standalone pet if the clipping
  matters.

  For the Clawd on Desk collection, `scripts/build-clawd-collection.py` reuses the existing
  Clawd V2 atlas as the default `clawd` variant and samples `clawd-on-desk`'s Calico APNG
  states and Cloudling GIF states into two V1 variants (`calico`, `cloudling`). That script
  expects the current Clawd `spritesheet.png` as `--clawd-sheet`.
