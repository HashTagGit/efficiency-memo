# Multi-variant pet packages

EfficiencyMemo's Codex Pet packages originally described one sheet per pet id, so mole-baby's nine Lamu forms would have appeared as nine independent pets in Pet Assistant. Keep one pet identity instead: a V3 manifest declares a `collection` of named variants inside the same package folder, each variant pointing at its own V1/V2 sheet. The catalog exposes one entry with a form picker, the selected variant is persisted per profile (`desktop_reminder_preferences.selected_pet_variant`, migration 0024), and the pet window receives `petId` plus `petVariant`. V1/V2 single-sheet packages remain valid and unchanged, imports of V3 packages require a ZIP so several sheets arrive together, and the seed/evolution forms are normalized to the standard 192×208 grid offline. This mirrors clawd-on-desk's theme picker (one list, independent appearance packs) while adding the whole-body form dimension that its theme variants intentionally cannot express.
