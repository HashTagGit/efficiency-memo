# Require review before Activity Assist becomes actual time

Activity Assist stores only short-lived foreground application identifiers and derives separate Activity Suggestions; it never captures titles, URLs, content, screenshots, or keystrokes. A suggestion contributes to CoreHour history, goals, Insights, or readable exports only after explicit Suggestion Acceptance creates an Actual Session through the existing validated manual-session path, preserving local-first usefulness without turning incidental computer activity into authoritative focus time.
